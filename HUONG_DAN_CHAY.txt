========================================================
  CostumeHub — Web cho thuê trang phục
========================================================

YÊU CẦU: Docker Desktop (đang bật) và Node.js 20.17 trở lên.

CÁCH CHẠY:
  1) Mở PowerShell / Terminal trong thư mục dự án.
  2) Lần đầu, tạo file cấu hình .env:
         node scripts/setup-env.js
  3) Chạy:
         docker compose up -d --build
     Mở trình duyệt vào:  http://localhost:3001

LỆNH HAY DÙNG:
  - Xem log:            docker compose logs -f web
  - Sửa .env xong:      docker compose up -d
  - Sửa code xong:      docker compose up -d --build
  - Dừng:               docker compose down
  - KHÔNG dùng "docker compose down -v" (xóa toàn bộ dữ liệu).
