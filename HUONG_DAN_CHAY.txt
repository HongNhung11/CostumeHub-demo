========================================================
  CostumeHub — Web cho thuê trang phục (50 sản phẩm)
========================================================

YÊU CẦU: Máy đích cần cài Node.js (bản 18 trở lên).
  Tải tại: https://nodejs.org  (chọn bản LTS)

CÁCH CHẠY (3 bước):
  1) Giải nén thư mục này ra.
  2) Mở Terminal / CMD / PowerShell ngay trong thư mục
     "CostumeHub-demo-main", gõ:
         npm install
     (chờ tải thư viện lần đầu — cần internet lúc này)
  3) Chạy app:
         npm start
     Rồi mở trình duyệt vào:  http://localhost:3000

GHI CHÚ:
  - Đã cấu hình sẵn chạy bằng SQLite (file .env), KHÔNG cần
    cài PostgreSQL. Lần chạy đầu tự tạo 50 sản phẩm mẫu.
  - Giao diện (Bootstrap) đã nhúng sẵn trong public/vendor
    nên hiển thị đúng kể cả khi mạng chặn CDN.
  - Muốn tạo lại dữ liệu từ đầu: xoá thư mục "data" rồi npm start.
