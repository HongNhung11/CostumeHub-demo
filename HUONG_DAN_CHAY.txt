========================================================
  CostumeHub — Web cho thuê trang phục
========================================================

YÊU CẦU: Docker Desktop (đang bật). Không cần Node. File .env tự tạo từ .env.example.

CÁCH CHẠY:
  - Windows:        bấm đúp CHAY_WEB.cmd
  - macOS / Linux:  sh chay-web.sh
  Xong mở trình duyệt vào:  http://localhost:3001

CẬP NHẬT: xóa thư mục cũ, tải bản mới, chạy lại y như trên. Dữ liệu vẫn còn.

LỆNH HAY DÙNG:
  - Xem log:            docker compose logs -f web
  - Sửa .env xong:      docker compose up -d
  - Sửa code xong:      docker compose up -d --build
  - Dừng:               docker compose down
  - KHÔNG dùng "docker compose down -v" (xóa toàn bộ dữ liệu).
